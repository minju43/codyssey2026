# Mini NPU Simulator

인공지능 가속기(NPU)의 핵심 연산인 **MAC(Multiply-Accumulate)** 원리를 외부 수치 연산 라이브러리 없이 순수 Python 반복문으로 구현한 패턴 판별 시뮬레이터입니다.

---

## 1. 실행 방법

1. **개발 환경**: Python 3.8 이상 (표준 라이브러리 `json`, `time`, `os`, `typing`만 사용)
2. **파일 구성**: `main.py`와 `data.json`을 동일한 디렉터리에 배치
3. **실행 명령어**:
    - `python3 main.py`
    - **1 입력**: 콘솔에서 3×3 필터 2개(A, B)와 3×3 패턴을 공백으로 구분해 입력하고 점수, 판정 결과, 평균 연산 시간을 확인
    - **2 입력**: data.json에서 크기별 필터(size_5, size_13, size_25)와 패턴을 로드하여 일괄 판정(PASS/FAIL), 크기별 성능 분석, 보너스 1차원 최적화 비교 및 결과 요약을 출력

## 2. 구현 요약
#### 1) 라벨 정규화(Normalization):
`data.json`에서 혼용되는 필터 키와 정답 라벨을 입력 단계에서 표준 라벨로 통일하여 문자열 표기 차이로 인한 비교 오류를 방지

#### 2) 순수 MAC 연산 구현:
NumPy 등 외부 라이브러리 없이 NxN 크기의 입력 패턴과 필터의 동일 위치 원소를 곱한 뒤 누적 합산하는 이중 반복문으로 구현

#### 3) 부동소수점 및 동점 비교 정책
실수 누적 연산 시 발생하는 이진 부동소수점 오차를 보정하기 위해 두 필터 점수의 차이가 1e-9 미만이면 어느 한쪽을 선택하지 않고 UNDECIDED로 처리

#### 4) 보너스 기능
- **메모리 접근 최적화**: 2차원 배열을 길이 N^2의 1차원 리스트로 평탄화하여 단일 루프로 연산하는 mac_1d를 구현하고 2D 방식과 속도를 비교
- **패턴 생성기**: 임의의 크기 N에 대해 표준 Cross, X 행렬을 자동 생성하는 generate_pattern 함수를 구현해 3x3 성능 측정에 활용

## 3. 결과 리포트
#### 3-1. 테스트 결과 및 실패 원인 분석
- **요약**: 총 6개 테스트 중 통과 3개(size_5_2, size_13_1, size_25_2), 실패(size_5_1, size_13_2, size_25_1)
- **원인 분류 및 진단**:
1. 데이터/스키마 검증: `data.json`의 모든 필터와 패턴은 키에서 추출한 크기 N과 실제 2차원 배열의 행/열 크기가 일치했으며 라벨 정규화가 정상 적용되어 스키마나 표기 불일치로 인한 오류는 발생하지 않음
2. 수치 비교 문제: 실패한 3개 케이스는 모두 로직 오류가 아니라 필터 가중치 설계와 허용오차 동점 판정 정책에 의한 결과
    - size_5_1: 0.1을 9번 누적 합산하는 과정에서 IEEE 754 부동소수점 오차가 발생해 0.9보다 미세하게 작은 값이 도출
    -> 1e-9 허용오차 정책이 정상 작동하여 오분류 대신 UNDECIDED로 판정, 기댓값과 달라 FAIL로 집계
    
    - size_13_2: 0.3을 25번 더한 Cross 점수에 부동소수점 누적 오차가 생겼지만 허용오차 범위 이내로 판정되어 동점 처리
    
    - size_25_1: 정중앙 가중치와 대각선 49칸 합의 차이가 허용오차 이내라 동점 처리되어 기댓값 대비 FAIL로 분류

#### 3-2. 성능 분석 및 시간 복잡도 (O(N^2))
|패턴 크기 (N×N)|평균 연산 시간 (ms)|총 곱셈-누적 연산 횟수 (N2)|
|3 × 3|0.0013 ms|9|
|5 × 5|0.0037 ms|25|
|13 × 13|0.0121 ms|169|
|25 × 25|0.0396 ms|625|

1. 시간 복잡도 근거
- MAC 연산은 가로 N, 세로 N 크기 2차원 배열의 모든 원소를 순회하며 곱셈 1회와 덧셈 1회를 수행하므로 핵심 연산 횟수는 N * N = N^2에 정확히 비례
- 실측 결과에서도 데이터가 커짐에 따라 평균 연산이 급격히 증가, 특히 3x3에서 25x25로 길이가 약 8.3배 증가할 때 연산 횟수는 69.4배, 실행 시간은 약 30.5배 증가하며 N^2에 비례하는 추세를 보임
2. [보너스] 메모리 접근 최적화 결과
- 2차원 중첩 리스트: `0.0348ms` / 1차원 평탄화 리스트 `0.0327ms`
- 2차원 배열의 이중 인덱스 참고를 1차원 연속 접근으로 단순화함으로써 반복문 오버헤드가 줄어 약 6%의 실행 시간 단축을 확인
